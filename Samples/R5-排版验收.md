# R5 排版验收

2026-11-10，`codex/r5`。本轮只验证 Web 文稿排版，不验证原生玻璃背景。

## 复现

在 `Web/` 中运行 `npm ci`，再运行 `npm run dev -- --host 127.0.0.1`。
打开 `http://127.0.0.1:5173/dev/doc-preview.html`；查询参数 `theme=light|dark`、`size=normal|large`。
开发页通过原始文本导入加载 `Samples/样张-排版.md`。正式构建只使用既有 index.html 入口，不包含开发页。

浏览器验收使用独立工具 Playwright 1.65.0，不新增项目依赖。准备该工具的 Chromium 后，在 Web 目录执行：

```sh
DEVBAR_PLAYWRIGHT_MODULE=/绝对路径/playwright/index.mjs node tests/doc-browser.mjs
```

## 截图条件和结果

Chromium 158，设备缩放 2；白、黑主题分别按 420×560、600×700 视口截整篇长图。
四张图在 `Screenshots/R5/`：light-normal、light-large、dark-normal、dark-large。
预览底色来自 tokens 的黑白底；这是静态文稿截图，不能证明原生玻璃透壁纸效果，也不代替 WKWebView 集成验收。

人工检查：段落、各级标题、引用、黑白任务框、代码、占位框可读；宽表和长代码在容器内滚动；正文页面不横向溢出；数字原文保持，显式对齐优先；长中文自然换行，无一字一行。

浏览器脚本覆盖清理脚本和事件、阻止任意内联样式、禁止非图片 src、保留 devbar/data 图片、外链图片占位、数字列、空列、三种对齐、普通点击拦截与命令点击回调、围栏原文和 Mermaid 惰性占位、缓存及页面横向溢出。拦截并断言外部网络请求为零；devbar 是宿主本地资源协议，在 Chromium 测试中直接拦截，不计为外部请求。

## 实现取舍

允许原始 HTML，但不保留任意 style 属性，以免 CSS 加载外部资源。表格 text-align 在清理前转为对齐 class，保留作者明确选择。
DOMPurify 会裁掉属性末尾空白，因此只对自身生成的 Mermaid 占位恢复惰性 data-src 源码；不插入可执行 HTML。
本轮没有 Shiki 或 Mermaid 渲染。链接回调由未来宿主接线；普通点击已经阻止导航。
