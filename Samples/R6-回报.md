# R6 · Codex · codex/r6

任务：T4.2 补充、T4.3、T4.4（含逐图配色）、T4.7 纯逻辑。最终提交号见本轮聊天回报及 `git log main..codex/r6`。

## 做了什么

- **T4.2 补充**：表格单元格最大宽度改为 `min(28em, 65cqi)`，随 `.prose` 的可见宽度变化；白主题行内代码使用 `--panel-control`。R5 样张四种组合重截为 `Screenshots/R6/r5-*.png`，原 R5 图片保留。浏览器断言长中文列宽受面板约束。
- **T4.3**：`shiki/core` + JavaScript 正则引擎，15 个指定语言模块、9 个别名、两份生成主题；全局复用同一个高亮器。未知语言及异常回退转义后的普通代码块，失败仅记录一次固定警告，不记录文稿。`createMarkdownPreview().renderAsync(text, theme)` 接入 fence 高亮；同步 `render()` 保留。切主题重新执行 `codeToHtml`。
- **T4.4**：Mermaid 按需加载、串行渲染、source/theme/layout 缓存（最多 64 项）、strict、base、neo、主题 secure、实际 SVG 尺寸、逐图错误卡片。`svgToPngBase64(svg, theme)` 生成 2 倍、不透明卡片底的 PNG，不调用桥接。ELK 只在显式比较时加载。
- **T4.4 配色**：`design/tokens.json` 收集 Mermaid 的主题角色与 Journey/C4 配置角色，由生成器产出 `mermaid-vars.ts`。覆盖派生分类色、sequence note/alt/loop、subgraph、Gantt、pie、gitGraph 等；普通图保留灰阶，作者 classDef/style 彩色保留。Sankey 使用节点灰阶映射；Journey 修正上游合并调色数组留下的彩色圆点，纯 SVG 标签；Journey/C4 默认文字另做 SVG 适配，C4 遇到显式 UpdateElementStyle/UpdateRelStyle 时尊重作者配置。
- **T4.7**：`detectDocMode` 和版本对应的 49 个关键字；`renderDocument` 整篇 Mermaid 分支。原文不改写。按容器维护渲染代次，离屏完成后仅提交最新结果，避免旧高亮/主题覆盖新内容。模式按钮、锁定状态、桥接接入不在本轮。

## 与规格的差异

1. **布局选项**：12.3.0 实际接口使用根级 `layout`；采用该接口，不使用规格示例中的 `flowchart.layout` / `state.layout`。默认常量暂定两类 Dagre，最终由审核确认。
2. **不实现 stripThemeConfig**：两种入口的 secure 实测均有效，不需要剥改源码。保留默认 secure 六项并追加主题、字体、HTML 标签、布局键；配置过滤递归生效。
3. **额外适配的依据**：12.3 的 Journey 配置数组与默认数组拼接，单靠 initialize 仍保留默认彩色；Sankey 默认用独立分类色；C4 默认节点文字硬编码白色。这些在渲染适配层处理，颜色来自生成变量，不改编辑区原文。C4 的显式专用样式命令不强制覆盖。
4. 本轮体积是独立网页模块的生产 ES 构建测量，非接入后的最终 app 体积。静态预览页不进入正式 Vite 入口。Chromium 的 HTTP 开发环境不能证明 `devbar://` / WKWebView 行为，后者留 R7。

## 交接与遗留问题

- Grok 接口：`renderDocument(root, text, {theme, mode})`；`detectDocMode(text)`；`svgToPngBase64(svg, theme)`。容器挂 `.prose`，放大加 `.large`；加载四份排版 CSS。链接使用既有 `bindPreviewLinks(root, onOpenLink)`，桥接和 UI 由宿主接。
- 关键字核对：逐项对照锁定 Mermaid 12.3.0 的 `dist/mermaid.core.mjs` 注册 detectors，排除内部 error/--- 检测器；49 个接受前缀分别有正例。此列表不承诺锁定/解锁 UI 已完成。
- `devbar://`、WKWebView JS 正则兼容、原生面板玻璃背景、真实桥接复制、模式按钮与锁定状态尚未验证，按分工留给宿主接入/R7；本轮没有改原生、bridge、main 或 Git 配置。
- 本轮独立复核发现的异步旧结果覆盖问题已补回归测试并修复；没有留待下一轮的已知代码缺陷。布局最终选择待审核。
