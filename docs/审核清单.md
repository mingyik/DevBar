# DevBar 审核清单

> 审核者（Claude）对每个任务的检查标准。实现者交付前也应自查。
> 结论分三种：**通过**、**修改后通过**（列出必须改的点，改完复核这些点即可）、**不通过**（违反红线或核心验收项未达成）。

## A. 每个任务都查

### A1 范围
- [ ] 只做了本任务的内容，没有顺手做其他任务、没有加功能（对照 `AGENTS.md` 红线 1）。
- [ ] 「与规格的差异」写清楚了；没写但实际有差异的，直接判「修改后通过」以上。

### A2 能跑
- [ ] 自己在本机重新运行 `Scripts/check.sh`，结果与回报一致（不只看回报里贴的输出）。
- [ ] 涉及界面或系统能力的任务：自己构建并运行 app，按验收项逐条操作一遍。

### A3 红线
- [ ] `grep` 检查：`fetch(`、`XMLHttpRequest`、`WebSocket`、`URLSession`（对外请求）、`eval(`、`new Function`、`unsafe-eval`、`AXIsProcessTrusted`、`CGEvent(` + `post`、`Vorssaint`（除抽取文件的版权头和 Reference 外）。
- [ ] 字面颜色值只出现在 `design/` 和生成产物里。
- [ ] 新增依赖：版本已锁定，许可证是 MIT / ISC / BSD / Apache 之一，有理由且必要。
- [ ] 日志不含用户内容。

### A4 代码质量
- [ ] Swift：没有 `@unchecked Sendable`、`nonisolated(unsafe)`，除非有注释说明且合理；没有强制解包处理外部输入。
- [ ] 错误路径有处理，用户可见的错误有中文文案，不吞错误。
- [ ] 没有遗留的调试代码、注释掉的大段代码、TODO 未在「遗留问题」里说明。
- [ ] 新逻辑有测试；测试测的是行为，不是实现细节；没有为了通过而改弱断言。

### A5 体验（界面类任务，**每轮都查**，不留到最后）
- [ ] 对照 `docs/UI基准.md` 逐条检查：玻璃质感、图标页签、标题行、卡片分组、无换行、无箭头无图标。
- [ ] 回报附齐 `docs/UI基准.md` §5 要求的 5 张截图；审核者自己再构建运行并截图对照。
- [ ] 白、黑两套主题都看过；放大面板看过。
- [ ] 文案是中文、简短、不含技术术语（错误信息里的语法错误原文除外）。
- [ ] 自动行为不打断、不覆盖、不猜改内容。

## B. 分领域重点

### B1 剪贴板（第 2 期）
- [ ] 本应用写入不被记成新条目（`lastSelfWrite`）。
- [ ] 隐私类型三种都被跳过；授权非「允许」时完全不读内容。
- [ ] 上限 10 条、20MB 图片拒收且系统剪贴板不变、原子写入、启动清理。
- [ ] 写回与拖拽给的是原始表示（对比字节），不是缩略图。
- [ ] 切换不改顺序；新复制后指针归零；HUD < 50ms 的测量方法可信。
- [ ] 终端让出名单生效且切走后恢复。

### B2 桥接与 WebView（T1.4 及以后）
- [ ] CSP 响应头与 meta 都在，且内容与规格一致。
- [ ] 外部请求确实被拦截（实际在 Inspector 里试）。
- [ ] 用户内容在信封里只是字符串；Swift 端没有解析 JSON 正文。
- [ ] 契约测试两端都跑。
- [ ] 切页、主题切换、内存释放后内容和（未释放时的）撤销历史都在。

### B3 工具（第 3 期）
- [ ] 无损链路测试逐步断言，且用的是方案 §9.5 指定的输入。
- [ ] `src/tools/`、`src/tree/` 没有原生 `JSON.parse` / `JSON.stringify`（ESLint 规则确实启用、确实会报错——故意写一个试试）。
- [ ] 不合法 JSON 没有被自动修改；「可修复」点击后才改，且可撤销；没有「修复了几处」。
- [ ] 识别保守：抽查方案 §9.5 和规格 §8.3 的反例；手动锁定类型后不跳。
- [ ] 复制规则与规格 §8.4 一致；二维码用的是待复制文本；2331 字节边界正确。
- [ ] 树：按需创建（展开前 DOM 里没有子行）、200 分批、箭头与复制按钮分离。

### B4 文稿（第 4 期）
- [ ] Shiki 用的是 `shiki/core` + JS 正则引擎 + 指定语言（检查打包产物里没有全量语言块）；失败回退普通代码块。
- [ ] Mermaid 版本锁定；【第 12 版】白 `theme: "default"`、黑 `theme: "dark"`，`secure` 仍包含 `theme`；图在不透明底上；逐图种在白、黑 × 默认 / 放大下确认文字可读、没有被玻璃底吞掉（颜色本身不再检查）；代码里没有字面颜色值。
- [ ] 文稿内 `%%{init}%%` / frontmatter 改主题无效；`classDef` / `style` 显式颜色保留。
- [ ] 宽图、宽表横向滚动且字号没被缩小（检查 SVG 没有残留 `max-width`）。
- [ ] 表格：无竖线；显式对齐优先；数字列自动右对齐只加 class、不改文本；长中文不出现一字一行。
- [ ] 一张图出错不影响其他内容。
- [ ] 样张四种组合截图齐全，人工比对可读性、裁切、滚动；代码高亮、JSON 树、排版的灰阶一致性（Mermaid 图除外）。

### B5 截图与长图（第 5 期）
- [ ] 抽取文件有原版权头 + `// Adapted for DevBar.`；`DevBarCapture` 独立编译。
- [ ] 删干净了窗口截图、全屏截图、标注、钉住、分享、辅助功能分支。
- [ ] 多屏、不同缩放下选区准确（看回报里的实测记录，抽查一项）。
- [ ] 长图失败时保留已拼部分。

### B6 录屏（已取消）
- 需求方于 2026-11-12 取消录屏；旧状态机、原型与验证记录仅作历史资料，不作为当前构建验收项。
