# DevBar 免费版安装说明

无需 Apple Developer Program 会员。此分发包使用 ad-hoc 本地签名，未经过 Apple 公证。接收者不需要开发者账号。

## 系统要求

macOS 26及以上。本包为构建机器对应架构；文件名含arm64时适用于Apple芯片Mac，不支持Intel Mac。

## 安装

1. 解压ZIP，将DevBar.app拖到“应用程序”。
2. 从Finder的“应用程序”双击打开。
3. 如果系统提示无法验证开发者，在确认来源可信后，打开“系统设置→隐私与安全性”，找到DevBar并点击“仍要打开”，按系统要求确认身份。设备管理策略可能禁止此操作，此时联系设备管理员。
4. 应用只显示在菜单栏，没有Dock图标。若被隐藏，检查“系统设置→菜单栏”的DevBar开关。
5. 使用Enter直接粘贴时，按需给DevBar辅助功能权限；普通复制与手动⌘V不依赖这项权限。使用截图时按功能提示授权。

请保留系统正常安全设置，无需关闭Gatekeeper。

## 更新

退出旧版后替换应用。用户数据默认在“~/Library/Application Support/DevBar”，或用户自己选择的位置，替换应用不清除这些数据。

ad-hoc签名在更新后可能导致辅助功能等授权需要重新添加。它也不保证消除macOS控制中心错误归属问题；若系统开关已开启却仍无图标，需按项目方案§9.1.1检查，不能通过重复安装来保证解决。

## 维护者打包命令

在项目根目录执行：

```sh
Scripts/package-free.sh
```

脚本构建Release，强制ad-hoc签名，验证签名后生成build/DevBar-free-macOS-<架构>.zip；包含应用及本安装说明。不会安装、启动或上传至公证服务。
