# 面板数据与内存方案

2026-11-12 需求方确认，覆盖旧方案中面板命名、路径及固定10条的描述。

## 目录与文件

默认 `~/Library/Application Support/DevBar/`。用户选择父目录后创建 DevBar；选择的目录本身已名为 DevBar 时不再套一层。四个子目录按需创建：Json、Paste、Markdown、QrCode。

Json、Markdown、QrCode：各一份 `state.json`，包含原文字符串、光标、模式、滚动位置。原子替换保存，原文里的 JSON 数字不解析成原生数字。不另存 content.txt，避免原文与状态两个文件只写成功一个；不积累时间戳版本，不存可重建的树、HTML、SVG、二维码图片。

Paste：`index.json` 存顺序、类型、摘要、文件名；`blobs/` 存独立原件（毫秒时间戳+UUID+表示序号），同一条记录保留纯文本/RTF/HTML等实际表示；`thumbs/` 存 UUID 命名的小缩略图。兼容已有 UUID 原件名。索引直接定位原件，不通过扫描目录寻找记录。

设置中历史上限为3–30条，默认10条；调小及新增时超限淘汰最旧项。拖到菜单栏删除、超限淘汰都清对应原件与缩略图。新记录在后台存储 actor 先写原件、原子提交索引，成功后更新列表；写入失败保留此前记录并提示。异常清理失败的孤立文件在下次初始化清理，不作为可恢复历史。

## 路径迁移

兼容旧 `state/*.json` 和 `clipboard/`，迁入对应面板目录；不改写原文。用户更换路径时先保存，再暂停新剪贴板采集、等当前采集完成；文件移动及配置切换在状态存储 actor 内串行，避免与后台保存交错。成功后重新打开 Paste 存储；重开失败则尝试移回原路径。

拒绝覆盖已有目标 DevBar，拒绝目标与源互相嵌套。选择取消不改变数据。磁盘权限/空间错误时反馈，保存失败不释放当前编辑内容。这里是用户数据，不提供把历史与原文当临时缓存清空的按钮。

## 内存

切换 Web 面板时串行处理：保存成功→清离开面板预览/渲染缓存→显示并按需生成新预览。切到 Paste 或设置时同样保存和清理。保留编辑器原文和撤销状态，公共 WebView 复用；不是每次切换销毁 WebKit 进程。

离开 Paste 时释放内存中的原件引用、缩略图、文本和悬停预览；再次使用时后台读回，快捷卡片等待完成后操作。原件尽可能用 mappedIfSafe 映射读取；超过128000字节的文本不为列表额外解码完整副本，悬停时再读。映射并不承诺零内存，也不是对所有文件系统都保证 mmap。

隐藏60秒及系统压力时保留上一批的保存/释放路径，保存失败或超时不销毁含未保存内容的视图。Mermaid缓存仍有64项/估算8MiB上限。

导入按当时系统可用页估算和严重压力判断，不按机器固定容量或374MiB判定：free+inactive+speculative页为可用估算，保留max(256MiB,物理内存/32)，输入字节不超过余量/48（预留解析、渲染副本与其他应用余量）。严重压力直接拒绝。此数值是保守准入预算，不保证未来分配必然成功；不声称系统监视器可用内存精确值。

粘贴、文本拖入、原生文件导入、自动带入剪贴板和新历史采集接入预算；拒绝时统一“内存不足，清理后再试。”。已有内容可复制出去。压力恢复后可重试。

## 截图目录

截图保存位置独立选择，默认桌面；直接写入所选目录，不创建 DevBar 父目录。当前 JSON/Markdown 截全图已接入；区域截图/滚动长图的正式保存功能尚未完成，本设置为它们保留统一路径来源，不声称已实现截图功能。
