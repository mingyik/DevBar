# T5.3 长图回滚定位与选区锁定

分支：main。提交范围：1157c6c（不含）至本记录所在提交（含）。

## 做了什么

复用现有灰度行匹配和切片拼接，维护有上限的已知位置关键帧。精确重访时纠正累计位置；反向或失配时尝试与旧关键帧重叠定位，多个候选位置冲突时暂停追加。回到已采集区间不重复添加，不删除或覆盖既有切片，不跨越缺失内容硬拼。

关键帧最多 8 份，像素数据合计最多 4 MiB，只存灰度样本，不留完整截图；优先保留采集范围两端。原有 120 秒／512 帧／6000 万像素上限、320 × 800 小预览、结束才合成整图的方式保留。正常连续匹配不额外做一遍全帧匹配。

首次可靠移动匹配后分离固定顶部和底部，后续只在移动内容上估算位移；固定顶部置于最终图顶端、底部置于末尾，各一次。顶部纯色留白缺少结构证据时不识别为固定顶栏。此检测针对静态条带，不声称覆盖所有动态吸顶栏。

长图选区窗口原本已穿透鼠标，本轮再在 SelectionView 内屏蔽采集后的 mouseDown／mouseDragged／mouseUp／keyDown，锁定框的位置和大小，防止事件直接进入视图后再次移动或确认。实际采集始终沿用最初的 CaptureRegion。

## 与规格的差异／公共文件

按需求方本轮要求支持回滚校正、固定顶部处理和长图选区锁定；同步方案 §7.4 与规格 §9.4。无新增依赖，无新增辅助功能调用，无自动滚动；修改仅限 DevBarCapture、对应测试及文档。
