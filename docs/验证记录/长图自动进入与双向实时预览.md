# T5.3 长图自动进入与双向实时预览

分支：main；起点：779444e；终点：本记录所在提交。

## 改动

长图拖选松开即采集；截图工具栏切入时直接沿用选区，不再先点一次对号。保留选框和附近的保存、取消、完成控制条（取消位置不变）。旁边新增实时等比预览，图像最多 320 × 800 像素。预览及控制条在创建屏幕采集过滤器前显示，排除自身窗口。

上下双向滚动使用视口坐标和已采集范围判断新增内容；上方新增前插，下方新增后接，经过已采集内容不重复追加，固定底栏只输出一次。原有时间、帧数、像素上限保留。未新增依赖、辅助功能或滚动事件发送。
