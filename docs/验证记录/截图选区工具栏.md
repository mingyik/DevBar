# T5 截图选区工具栏

需求方决定：截图松手后进入选区编辑；保留保存，取消另存为及复制入口，不增加自动滚动。

## 实现

- 选区移动、八个调整点、尺寸提示、屏幕内浮动工具栏。
- 矩形、椭圆、箭头、画笔、文字（回车确认）、马赛克、高亮和撤销。
- 标注合成到原生像素图像；保存沿用设置中的目录和文件名规则。
- 工具栏可进入手动长图；独立长图入口圈选后显示开始/取消，采集后沿用完成/取消。
- 保存只落盘，不再额外写系统剪贴板。

## 来源与差异

- 继续使用从 Reference 抽取的选区骨架、截图采集和长图算法。
- 本轮选区内编辑及工具栏是本地精简实现，没有搬入原项目的完整独立编辑器；不包含分享、贴纸、画布扩展、AI、自动滚动。
