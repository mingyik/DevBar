# T5.2 截图编辑修复

- 编辑开始后取消初始选区超时；选区外点击仅提交文字、取消对象选择，不重建或清空选区。
- 箭头等绘图操作要求至少 3pt 拖动，单击不创建对象。
- 选择图标改为手形，马赛克改用 aqi.medium，文字用独立模板 T 图标。
- 马赛克改为沿拖动轨迹涂抹；绘制时显示像素化结果，导出沿用相同路径。
- 二级工具栏提供系统颜色和线宽控制；文字使用字号控制。颜色、线宽、字号按标注保存。选中旧标注后可以调整样式。
- 本轮彩色标注是需求方明确要求，属于对现有黑白限制的截图标注例外；不增加钉图。

验证：Scripts/check.sh 和免费 release 打包通过。新增 annotationClickRequiresDragAndOutsideClickPreservesSelection 覆盖单击不创建箭头、拖动后撤销可用、外部点击后保存仍保留原选区尺寸。

待实际验收：编辑持续超过一分钟、点击其他背景、马赛克涂抹效果及性能、颜色/粗细/字号的真实窗口外观。没有将这些人工场景报告为已验证。
