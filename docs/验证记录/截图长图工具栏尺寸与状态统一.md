# 截图长图工具栏尺寸与状态统一

T5.2 / T5.3，main。

- 截图、长图选区主工具栏由 50pt 改为 45pt，按钮高由 40pt 改为 35pt，分割线和位置随之对齐。
- 主工具与二级模式图标由 20pt 改为 18pt；原有文字 T 随之由 23pt 改为 21pt，保持原图标造型。
- 长图采集进度条由 48pt 改为 43pt，出现对齐提示时由 68pt 改为 63pt。
- 二级模式按钮复用主工具栏按钮，实现一致的悬浮与选中背景。背景明暗取自 App 注入的主题图标色，不再错误依赖系统当前外观。
- 普通图标、禁用图标继续使用统一 icon.primary / icon.disabled，选中蓝色、调色板等语义状态保留。
- 设置和菜单入口使用“截图”“长图”，不再显示“区域截图”。

## 验证

- Scripts/check.sh 退出码 0，Swift 155 项、Web 355 项通过。
- screenshotToolbarUsesConsistentColorsInBothAppearances 在 aqua / darkAqua 下构建真实工具栏，检查高度、按钮边界、正常/选中/禁用颜色，点击箭头后检查二级模式按钮复用了相同控件。
- 长图选区测试确认高度 45pt，三个操作按钮且无播放按钮和分割线。
- Release 构建安装后，实际壁纸下的玻璃效果及手感由需求方确认；不以状态测试替代人工视觉验收。
