### T4.7 / T4.4：R6 审核并入

- 删除直接依赖 @mermaid-js/layout-elk 和 @shikijs/themes；删除 ELK 类型、懒加载、对照页参数，渲染布局固定 dagre。

- 证据：R7-网页回归.json，Web/tests/doc-mode.test.ts、doc-r7-browser.mjs 等测试。

### T1.4：WebView 更换与编辑命令

- WebHost 可观察，重建会通知 SwiftUI；容器检查实际挂载对象并替换旧 WKWebView，同时处理启动占位视图。

- 需求方已实测六个按键，回复“六个按键都正常”。没有模拟按键，也没有辅助功能调用。
- 证据：R7-WebView-自检1.json、R7-WebView-自检2.json，WebHostObservationTests.swift、EditingCommandsTests.swift。

### T1.2：五页骨架与第 3 版 UI

- 顺序为 clipboard → json → encode → qr → doc；标题点击、CmdP / ShiftCmdP 循环，保存上次页面。只有剪贴板实装内容，另四页为输入块 / 结果块占位。

- 0.15 秒内容淡入淡出、尺寸变化；顶部固定，小屏幕按顶部到底边剩余高度收缩。修复快速切页、关闭重开时旧动画目标覆盖新尺寸的问题。
- 设置增加系统声音 / 麦克风（默认关）、默认打开页、五个 KeyboardShortcuts 页面录制控件（默认空）。同页且已打开时页面快捷键收起，否则打开指定页。CtrlOptionD、OptionCmdJ 保持原有按键。
- 菜单栏右键的区域截图 / 长图 / 开始录屏入口本轮置灰。
- glassTint：白 0.24→0.18，黑 0.19→0.14；彩色壁纸实拍核对。圆角：面板 16，内容块 14，按钮 8。
- JSON 内容块新增 panel.inset（白：黑色 0.035；黑：黑色 0.18），借背景层次区分内容与外层玻璃；颜色仍只来自设计变量。

### T2.3：列表与页内详情

- 最多 10 条，颜色色块、原始图片缩略图、空状态、授权说明、单条删除、清空二次确认；满 10 条时清空按钮仍可见。
- 用户在本轮追加的外观要求优先于旧规格：不显示来源或时间，仅显示文本 / 图片 / 文件类型；每条细边框包围，选中项用背景色区分；不画行间分割线，不画左侧指示条；各页标题下不画分割线，标题与内容另留 8pt。原生滚动内容右侧预留 10pt；剪贴板滚动区再向右扩 8pt、内部预留 18pt，内容位置保持不变，指示条接近面板右缘且不压在内容上。
- 背景跟随 focusedIndex，方向键移动即可看到选中项变化；回车写回原始表示并进入页内详情。详情只在当前面板内显示，提供返回列表和复制。纯文本用完整原文，图片用原图，文件列全量 URL；RTF 提取文本，HTML-only 显示原始源码，不加载外部资源。
- 图片超过 20MB 且历史为空时，底部错误仍可见。详情条目被删后返回列表。

- 以上四项列表外观及标题去线、JSON 内层背景按本轮需求方最新明确意见执行，覆盖此前 UI 基准的来源 / 时间 / 指示条 / 标题分割线规定；没有修改方案和规格正文。

- @shikijs/themes 已从直接依赖删除，仍由 shiki 4.6.0 间接引用，锁文件保留该传递依赖；flowchart-elk 仍是 Mermaid 12 的检测关键字，不代表保留 ELK 布局依赖。
