# 截图原位切换长图

T5.3，main。

- 截图框内点击长图图标，只清除冻结背景并切换下方三个按钮，不再确认并关闭选区。保留原选框坐标；长图 X 位置不变。
- 确认后保留蓝色边框、尺寸标签；选区窗口转为鼠标透传并释放键盘焦点，允许用户滚动原应用。
- 采集控制条按选区右下方放置，下方空间不足改为上方，最终限制在选区屏幕可见范围内。采集结束或取消时清理选区覆盖层。
- 蓝框和控制条都在 ScreenCaptureKit 获取过滤列表之前显示，沿用排除本进程窗口的采集过滤器；不能把自身 UI 拼入长图。
- 结束后的短暂结果通知仍使用原通知位置。
