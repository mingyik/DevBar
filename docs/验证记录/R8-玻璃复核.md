# R8：R7 玻璃并入项

在 macOS 26.7.2、2× 屏幕、系统默认彩色壁纸上重拍；降低透明度、增强对比度均关闭。先保存窗口显隐状态，临时隐藏其他窗口，拍完恢复，未改壁纸。

R7 的截图方式包含 window-only 捕获，不能保留真实背后桌面；本轮改用屏幕区域截图，另有带 20pt 桌面上下文的白主题剪贴板图，能对照壁纸的蓝色天空与青色水面透色。所有条目是隔离测试内容。

首次叠色白 0.18、黑 0.14 仍偏重；在 design/tokens.json 将白、黑 panel.glassTint 均降为 0.08，再经 Scripts/gen-tokens.ts 生成。正文角色与文字对比度没有变。最终图已目视检查，白主题不再是灰色不透明底，黑主题也能透出壁纸色。
