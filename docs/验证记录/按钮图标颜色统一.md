# 按钮图标颜色统一

任务 T1.2，main。范围仅为按钮内图标颜色。

## 检查发现与处理

| 位置 | 原不一致 | 处理 |
|---|---|---|
| Web 页面底部按钮 | 正常色为 icon.primary，禁用额外叠加 0.6 透明度 | 使用显式 icon.disabled，取消叠加透明度 |
| Web 其他图标按钮、并排输入清空 | 继承正文色，禁用额外叠加 0.45 | 统一正常与禁用图标变量 |
| Mermaid 单图复制 | 正文色加 0.75 透明度 | 使用图标变量，不再额外变淡 |
| 主面板顶栏、返回、目录按钮 | text.secondary 等正文变量 | 仅 Image 使用图标变量 |
| 设置文件夹、系统设置与箭头 | 继承正文色 | 仅 Image 使用图标变量，随 isEnabled 切换 |
| 目录最近文件按钮内时钟 | text.tertiary | 使用图标变量 |
| 截图进度条与截图编辑工具栏 | 系统 labelColor / disabledControlTextColor | 由 App 注入统一主题图标色 |

浅色正常 #333333、禁用 #999999；深色正常 #D9D9D9、禁用 #777777。颜色集中在 design/tokens.json 并生成 Swift/CSS。

正文、非按钮空状态图标、拖动手柄、按钮背景和布局保持原有设置；截图工具选中蓝色、颜色选项和删除红色等语义状态保留。系统菜单、文件选择器及外部快捷键录入控件保持系统自身样式。

## 验证
