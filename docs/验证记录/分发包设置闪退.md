# 分发包设置闪退排查（2026-11-14）

已确认缺陷：原 build-app.sh 只复制 DevBar_DevBar.bundle，漏掉 KeyboardShortcuts_KeyboardShortcuts.bundle。设置页 RecorderCocoa 初始化读取 record_shortcut 本地化字符串，会访问 Bundle.module。生成的访问器只尝试 app 根目录和构建机绝对路径，因此开发机可以兜底，分发机器不能。

修复：打包所有 SwiftPM .bundle 到 Contents/Resources；构建前对锁定版本 KeyboardShortcuts 1.10.0 的 Utilities.swift 本地化入口施加可重复的受检补丁，优先从 Bundle.main 资源目录加载，随后才用原 .module。补丁仅改构建缓存，脚本随仓库提交；上游源结构变更时明确报错。资源文件复制后确保拥有者可写，再清扩展属性并签名。

验证：release 重编译依赖并打包成功；脚本语法检查、ZIP 内资源清单与 codesign --verify --deep --strict 通过。另一台机器设置页尚待复测；未获得其崩溃日志，不能排除其他原因。
