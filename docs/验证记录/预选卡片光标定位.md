# T2.4 预选卡片光标定位

分支：`main`；实现提交：`2b676a1`。

## 做了什么

- 首次显示卡片时，后台查询已授权前台应用的插入光标坐标；仅查询范围和几何，不读取文本，也不主动弹授权。
- 光标上方预留输入法空间；上方空间不足时选择下方，再约束在屏幕可见范围。
- 光标不可用时使用鼠标；鼠标也不在任何屏幕时以屏幕中心为最后兜底。连续切换时不再采用迟到的查询结果。
- 按需求方决定同步补充 `AGENTS.md` 红线 7 的光标定位例外。

## 与规格的差异

- 对支持辅助功能的前台应用增加只读光标位置查询；查询在后台执行，每个 AX 对象的消息超时为 50 毫秒。
- 卡片立即出现在兜底位置，后台结果返回后定位到光标；快速切换或关闭卡片后不再应用迟到结果。

## 测试与检查

- `clipboardCardCaretPlacementPrefersAboveAndFallsBelow`：测试上方优先、顶部边缘转到下方和左右边缘约束。
- `clipboardCardFallbackCentersWhenPointerIsOutsideScreens`：测试鼠标位置无效时居中。
- `Scripts/check.sh` 通过：Swift 124 项、Web 350 项。

## 验收证据与遗留问题

- 自动测试覆盖定位几何；实际输入法候选窗口、不同应用的辅助功能支持及多屏行为未做人工实测，需需求方验证。
- 不同应用可能不提供有效光标位置，此时按鼠标和屏幕居中的顺序兜底。
