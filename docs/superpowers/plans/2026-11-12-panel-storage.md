# 面板数据存储与内存释放实施方案

用户已要求本会话直接完成，在 main 实施并逐项提交。

目标：面板标题 Json / Paste / Markdown / QrCode；磁盘保存用户数据，切换时保存成功后释放预览；可选择数据位置和独立截图位置。

## 存储约定

默认 ~/Library/Application Support/DevBar；选择父目录后使用其下 DevBar，避免重复套 DevBar。按需建立 Json、Paste、Markdown、QrCode。
Json / Markdown / QrCode 各用一个 state.json 原子保存原文字符串及模式、光标等状态。原文是 JSON 字符串，不解析其中的 JSON 数字；不生成时间戳历史。用单文件保证原文和状态一起提交，避免两个文件写到一半不一致。
Paste 保留 index.json 索引、blobs 独立原件和 thumbs 缩略图；新原件使用时间戳+UUID文件名，索引负责查找、去重和顺序，不扫描目录。上限在设置中配置3–30条，默认10条；兼容旧文件名。
已有 state/ 与 clipboard/ 自动迁移，保留内容。修改数据路径先保存并暂停监听，迁移成功后切换配置、重开存储；失败继续用原路径。拒绝覆盖其他已有 DevBar 数据、拒绝嵌套到自身目录。界面称“数据存储位置”，不提供删除用户原文的清缓存按钮。
截图位置默认桌面；直接写入用户所选目录，不创建 DevBar。暂未实现的区域/滚动截图正式落盘不伪造已接入；现有文稿/JSON截全图接入同一设置。
