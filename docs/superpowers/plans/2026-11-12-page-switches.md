# 页面切换开关与 Markdown 模式预留

需求方已明确本轮行为，直接在main实现。

- 设置页保留图钉，隐藏重复的设置按钮。
- 页面快捷键每行前有switch，默认全开；关闭只排除普通切页，专属快捷键仍可直达。至少保留一个开启。
- Cmd+P及点击标题仅遍历开启页面，从专属快捷键打开的关闭页继续切换时跳到它后面的开启页，末尾循环。
- 普通打开不落到已关闭页；默认页面选择仅展示开启页。关闭当前固定默认页时改成上次页策略，下一次普通打开回到开启页。
- 偏好持久化；旧用户全开，损坏/空列表恢复Paste。
- Cmd+Shift+P立即退出反向切页用途，留给未来Markdown模式。未来模式按钮和该快捷键循环“仅编辑→仅预览→边编辑边预览”，第三种增加扩展预览窗口；此为后续产品计划，本轮不创建该窗口。

实施：PanelModel管理偏好及不变量；PanelView显示switch和设置图钉；DevBarPanel只拦截Cmd+P；Shortcuts原有直达保持。验证筛选循环、关闭最后一项被拒、重启偏好、关闭页面仍可直达及Shift+Cmd+P不再调用切页。
