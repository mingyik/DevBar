# DevBar UI 基准

> 2026-11-10 由需求方确定。面板外观以本文为准；与 `docs/实现规格.md` §6.2、§6.3 冲突时以本文为准。
> 对照图：`docs/UI参考/参考-面板质感.png`（玻璃质感）、`docs/UI参考/参考-CodexBar布局.webp`（布局：分隔线代替卡片、左右信息分层）、`docs/UI参考/R2-初版-待改.png`（R2 初版，问题见 §4）。
> **【第 3 版补充，2026-11-11】** 页面拆成 5 页（剪贴板 / JSON / 编码 / 二维码 / 文稿），顶栏、分隔线、玻璃等规格不变；页名是几个字就显示几个字，不换行。编码、二维码页内容少，不显示放大按钮，面板保持默认尺寸。
> **【第 2 版，2026-11-10】** 需求方改为：**去掉页签栏，不做侧边栏**，一次只显示一页，⌘P 切换；截图录屏不在面板里；布局参考 CodexBar，少用卡片。§1、§3 按此重写。

## 1. 要什么、不要什么

| 要 | 不要 |
|---|---|
| Vorssaint 参考图的**通透玻璃质感**：能隐约透出桌面壁纸的颜色 | 参考图顶部的**小箭头**、**品牌图标** |
| CodexBar 的**分隔线分组**：内容直接铺在玻璃上，段与段之间一条细线 + 留白 | **页签栏、侧边栏**（R2 做的图标页签轨道要删掉） |
| CodexBar 的**左右信息分层**：左边标题 / 内容，右边灰色小字（时间、来源、数量） | 嵌套的**卡片框**（玻璃上再套一层卡片） |
| 页面名字 + 灰色「⌘P」提示，告诉用户怎么切换 | **彩色**：蓝色选中、彩色细条一律不用 |
| 任何标签都不换行 | 面板里的截图录屏页 |

## 2. 面板背景（玻璃）

参考实现：`Reference/Vorssaint/Sources/Vorssaint/UI/Theme.swift` 的 `PanelGlassSurface`、`UI/SharedUI.swift` 的玻璃背景。

| 系统 | 做法 |
|---|---|
| **macOS 26**（唯一支持的系统） | SwiftUI `.glassEffect(.regular, in: RoundedRectangle(cornerRadius: 12, style: .continuous))`，上面只叠一层**很淡**的底色 `panel.glassTint`（白主题约白 24%、黑主题约黑 19%；即参考实现里 `baseFill × 0.35 / × 0.45`），再加 0.7pt 描边。**不再叠满 `panel.base`** |
| 系统开启「降低透明度」 | 不用玻璃，用不透明的 `opaqueBackdrop` + `panel.base` |

- 玻璃的外观（`appearance`）必须跟随 DevBar 的白 / 黑设置，而不是跟随系统，否则手动选白主题时材质仍是深色。
- 顶部高光：保留参考实现 `rimHighlight` 的做法（0.7pt 描边从上到下由亮变暗），不用整块渐变色带。
- 新增设计变量 `panel.glassTint`（白、黑各一），由 `design/tokens.json` 生成，不在代码里写数值。

## 3. 布局

```
┌──────────────────────────────────────────┐
│  剪贴板  ⌘P                      📌 ◐ ⤢  │  ← 顶栏：页面名字（可点，点了切下一页）+ 灰色「⌘P」；右侧 3 个按钮
│  ──────────────────────────────────────  │  ← 0.7pt 分隔线
│  SELECT * FROM users WHERE …       刚刚  │  ← 列表行：左内容，右灰色小字
│  ──────────────────────────────────────  │
│  https://example.com/a?b=1      3 分钟前 │
│  ──────────────────────────────────────  │
│  …                                       │
└──────────────────────────────────────────┘
```

| 元素 | 规格 |
|---|---|
| 面板尺寸 | 默认 420×560；「工具」「文稿」可放大到 600×700（不变） |
| 面板外边距 | 左右 16pt，顶部 12pt，底部 12pt |
| 顶栏 | 高 32。左：当前页名字（剪贴板 / 工具 / 文稿），15pt 半粗，`text.primary`；名字后 6pt 处一个「⌘P」，11pt，`text.tertiary`。名字本身可点击，点一下切到下一页，悬停时名字下方出现 0.7pt 下划线。右：钉住、白/黑、放大 3 个图标按钮，24×24，图标 13pt，无底色，悬停时出现 `panel.control` 圆角 7 底；钉住时图标用实心版本；放大只在「工具」「文稿」页显示，其他页不占位 |
| 顶栏下分隔线 | 0.7pt，`line.divider`，左右与内容对齐（不顶到面板边） |
| 内容区 | **不套卡片**，直接铺在玻璃上。剪贴板：列表行之间 0.7pt 分隔线；工具 / 文稿：编辑区和预览区直接铺满内容区，只在顶部有分隔线 |
| 列表行（剪贴板） | 行高 52；左：内容预览（13pt，最多两行），右：时间（11pt，`text.tertiary`，右对齐）；来源应用小图标放在时间左边；当前条目整行用 `panel.control` 圆角 7 底 + 左侧 2pt 竖条（文字色），不用整行反色 |
| 次要信息 | 一律 11pt、`text.tertiary`、右对齐；与左侧内容基线对齐 |
| 切换动画 | ⌘P 切页时内容淡入淡出 0.15 秒，顶栏名字同步更新；不做左右滑动 |
| 文字 | 任何位置的标签都不允许换行；放不下时缩短文案，不缩小字号 |
| 代码块、表格、Mermaid 图 | 仍各自放在圆角 10 的浅底块里（`panel.card`），这是内容本身的容器，不算「卡片套卡片」 |

## 4. R2 初版的问题（对照 `R2-初版-待改.png`，历史记录）

1. 页签写了文字，「剪贴板」「截图录屏」换行，四个页签宽度不一。→ 改为只放图标的等宽页签。
2. 背景太闷：旧式材质上叠满 42% 黑，几乎看不到透明感。→ 按 §2 改。
3. 页签栏和内容之间有横线，内容没有卡片分组。→ 按 §3 改。
4. 三个操作按钮有方块底色，和页签抢视觉。→ 移到页面标题行右侧，平时无底色。

## 5. UI 验收方式（每轮都做）

凡是改了界面的轮次，回报里必须附**截图**，审核时逐张对照本文：

- 白、黑两套主题 × 默认 / 放大两种尺寸，共 4 张；
- 再加一张：黑主题放在**彩色壁纸**上（检查玻璃透出的效果）；
- 截图存进 `Screenshots/<轮次>/`，文件名写明主题和尺寸。

截图条件：显示缩放默认、系统未开「降低透明度」与「增强对比度」（另有专门的高对比验收时除外）。
