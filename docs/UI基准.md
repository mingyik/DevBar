# DevBar UI 基准

> 2026-11-10 由需求方确定。面板外观以本文为准；与 `docs/实现规格.md` §6.2、§6.3 冲突时以本文为准。
> 对照图：`docs/UI参考/参考-面板质感.png`（目标质感）、`docs/UI参考/R2-初版-待改.png`（R2 初版，问题见 §4）。

## 1. 要什么、不要什么

| 要 | 不要 |
|---|---|
| 参考图的**通透玻璃质感**：能隐约透出桌面壁纸的颜色 | 参考图顶部的**小箭头**（我们是独立面板，不是系统气泡） |
| 参考图的**图标页签栏**：一条圆角轨道里放一排图标，选中项填充 | 参考图里的**品牌图标**（土星 logo），面板顶部不放任何图标 |
| 参考图的**卡片分组**：内容放在浅色卡片里，卡片有细描边 | 参考图的**蓝色选中色**：我们只有黑白，选中用反色或凸起填充 |
| 页签栏下方一行**页面标题**（参考图的「保持唤醒」位置） | 页签里写文字导致**换行**（R2 初版「剪贴 / 板」「截图录 / 屏」） |

## 2. 面板背景（玻璃）

参考实现：`Reference/Vorssaint/Sources/Vorssaint/UI/Theme.swift` 的 `PanelGlassSurface`、`UI/SharedUI.swift` 的玻璃背景。

| 系统 | 做法 |
|---|---|
| **macOS 26**（唯一支持的系统） | SwiftUI `.glassEffect(.regular, in: RoundedRectangle(cornerRadius: 12, style: .continuous))`，上面只叠一层**很淡**的底色 `panel.glassTint`（白主题约白 24%、黑主题约黑 19%；即参考实现里 `baseFill × 0.35 / × 0.45`），再加 0.7pt 描边。**不再叠满 `panel.base`** |
| 系统开启「降低透明度」 | 不用玻璃，用不透明的 `opaqueBackdrop` + `panel.base` |

- 玻璃的外观（`appearance`）必须跟随 DevBar 的白 / 黑设置，而不是跟随系统，否则手动选白主题时材质仍是深色。
- 顶部高光：保留参考实现 `rimHighlight` 的做法（0.7pt 描边从上到下由亮变暗），不用整块渐变色带。
- 新增设计变量 `panel.glassTint`（白、黑各一），由 `design/tokens.json` 生成，不在代码里写数值。

## 3. 布局

```
┌──────────────────────────────────────────┐
│  ┌────────────────────────────────────┐  │  ← 页签轨道：圆角 10，卡片色 + 细描边
│  │  [📋]    [🛠]    [📄]    [📷]      │  │    4 个图标等宽；选中项圆角 7 的反色填充
│  └────────────────────────────────────┘  │
│  剪贴板                         📌 ◐ ⤢  │  ← 页面标题（13pt 中粗，次要文字色）+ 3 个操作图标
│  ┌────────────────────────────────────┐  │
│  │                                    │  │  ← 内容卡片：圆角 10，卡片色 + 细描边，内边距 10
│  │             内容                   │  │
│  │                                    │  │
│  └────────────────────────────────────┘  │
└──────────────────────────────────────────┘
```

| 元素 | 规格 |
|---|---|
| 面板外边距 | 14pt；各块之间 10pt |
| 页签轨道 | 高 28（需求方 R2 要求收小，原为 36），圆角 10，`panel.card` 填充 + `line.border` 0.7pt 描边；内边距 3 |
| 页签 | 只放 SF Symbol（13pt，常规字重；需求方 R2 要求收小，原为 16pt），4 个等分宽度；**不写文字**；悬停显示提示文字（剪贴板 / 工具 / 文稿 / 截图录屏）；可访问性标签同提示文字 |
| 选中页签 | 圆角 7 的反色填充（黑主题白底黑图标，白主题黑底白图标）；切换时 0.15 秒过渡 |
| 页面标题行 | 左：当前页名称，13pt 中粗，`text.secondary`；右：钉住、白/黑、放大 3 个图标按钮，24×24，无底色，悬停时出现 `panel.control` 圆角 7 底；钉住时图标用实心版本 |
| 放大按钮 | 只在「工具」「文稿」页显示，其他页不占位（右侧只剩两个） |
| 内容区 | 放在卡片里（圆角 10，`panel.card` + 0.7pt 描边，内边距 10）；剪贴板列表、工具编辑区、文稿编辑区都在卡片内 |
| 分隔线 | 页签栏和内容之间**不画横线**，靠间距和卡片分组 |
| 文字 | 任何位置的标签都不允许换行；放不下时缩短文案，不缩小字号 |

## 4. R2 初版的问题（对照 `R2-初版-待改.png`）

1. 页签写了文字，「剪贴板」「截图录屏」换行，四个页签宽度不一。→ 改为只放图标的等宽页签。
2. 背景太闷：旧式材质上叠满 42% 黑，几乎看不到透明感。→ 按 §2 改。
3. 页签栏和内容之间有横线，内容没有卡片分组。→ 按 §3 改。
4. 三个操作按钮有方块底色，和页签抢视觉。→ 移到页面标题行右侧，平时无底色。

## 5. UI 验收方式（每轮都做）

凡是改了界面的轮次，回报里必须附**截图**，审核时逐张对照本文：

- 白、黑两套主题 × 默认 / 放大两种尺寸，共 4 张；
- 再加一张：黑主题放在**彩色壁纸**上（检查玻璃透出的效果）；
- 截图存进 `Screenshots/<轮次>/`，文件名写明主题和尺寸。

截图条件：显示缩放默认、系统未开「降低透明度」与「增强对比度」（另有专门的高对比验收时除外）。
