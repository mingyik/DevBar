# DevBar 使用说明与引导视频制作提纲

依据：[当前产品方案（第 13 版）](../菜单栏工具方案.md)，更新于 2026-11-14。

本文是后续制作的提纲，不代表视频已拍摄或每项交互已人工验收。正式出稿前按“录制前核对”检查当前安装版本。

## 1. 使用说明目录

1. **安装与首次启动**：支持系统、免费安装包、菜单栏入口、首次允许运行。
2. **认识面板与快捷键**：四页、⌘R 打开和循环、⌘W 收起、标题切页、图钉和放大。
3. **Paste**：记录与授权、点击和上下选择、拖出、悬浮预览、顶部拖动删除。
4. **快速粘贴**：⌘⇧V、方向键、Enter 与 Esc、可选辅助功能、未授权时手动 ⌘V。
5. **Json**：输入与格式转换、折叠、转义、编解码、复制与撤销；展示当前实际入口。
6. **QrCode**：输入、预览、复制 PNG、回到编辑。
7. **Markdown／Mermaid**：两态预览、代码、图表、单图复制、纯 Mermaid、文本文件拖入。
8. **截图**：⌘⇧A、圈选与调整、基础标注、独立工具样式、保存。
9. **手动长图**：⌘⇧L、开始后自己滚动、✓ 复制、保存落盘、× 取消、对齐失败。
10. **设置与数据**：主题、排序和循环开关、可改快捷键、历史 3–30 条、数据与截图目录、权限状态。
11. **常见问题**：重启清空文本而历史保留、尺寸重置、快捷键冲突、权限、长图上限、接收机设置闪退。

每节统一写法：用途 → 操作入口 → 最短步骤 → 得到什么结果 → 限制／失败时怎么办。用户正文不需要框架名、提交号、测试数量或内部桥接消息。

## 2. 视频建议：先核心，再分章节

可做一条约 5–7 分钟的引导，也可按下面分镜拆成短视频。时长为编辑预算，不是性能指标。

| 镜头 | 操作 | 应出现的画面／讲解点 | 对应方案 |
|---|---|---|---|
| 01 · 入口（20 秒） | 启动，点菜单栏；⌘W 收起；⌘R 打开并循环 | 四个页面逐一出现；快捷键字幕；不演示旧 ⌘P | §1–2 |
| 02 · 设置（25 秒） | 拖动页面排序，关闭其中一个循环开关，再切页 | 跳过关闭页；至少保留一页；快捷键可修改 | §1.2、§2 |
| 03 · Paste（40 秒） | 复制两段示例文本和一张示例图；点击条目；上下切换 | 当前条目竖线、系统剪贴板内容、悬浮扩展预览 | §4.1 |
| 04 · 快速粘贴（35 秒） | 在测试输入框按 ⌘⇧V、方向键、Enter | 先确认已有授权；目标输入框收到内容；Esc 只取消 | §4.3 |
| 05 · 拖拽（25 秒） | 拖文本到测试编辑器；拖图片到测试文件夹；顶部删除一条测试记录 | 拖出结果、红色删除反馈；只用可丢弃测试条目 | §4.2 |
| 06 · Json（35 秒） | 粘贴示例 JSON；转换、折叠、转义、撤销 | 操作与显示一致；长整数写法不变；按钮执行动作 | §5.1–5.2 |
| 07 · QrCode（20 秒） | 输入示例链接，切预览并复制 | 看到二维码；说明预览态复制 PNG、编辑态复制文本 | §5.3 |
| 08 · Markdown（40 秒） | 示例文稿切预览；查看代码、表格、Mermaid | ⌘E 两态；超宽容器横向滚动；单图错误不影响正文 | §6 |
| 09 · 文件与截全图（25 秒） | 拖入样张；点击截全图，Finder 显示 | 文件只读不写回；导出包含视口外内容；与滚动截屏区分 | §6.1–6.2 |
| 10 · 区域截图（50 秒） | ⌘⇧A、圈选、缩放范围、矩形、文字、箭头、马赛克 | 松手后保留；大头／普通、涂抹／框选；无钉图或荧光笔 | §7.1–7.2 |
| 11 · 输出区别（20 秒） | 演示保存，Finder 显示 | 保存写入配置目录，不出现另存为 | §7.3 |
| 12 · 手动长图（40 秒） | ⌘⇧L、开始、手动慢滚、✓；粘贴到测试目标 | 用户自己滚动；✓ 结束并复制；保存为另一输出动作 | §7.4 |
| 13 · 重启与收尾（20 秒） | 关闭并重开应用，展示页面状态 | Paste 保留；Json／QrCode／Markdown 为空、小尺寸；设置保留 | §8 |

首次授权建议单独录成可选片段，避免每个功能镜头重复弹系统窗口。不要为了拍摄任意重置系统隐私数据库。

## 3. 演示素材

- 文本：两行短文、一段多行长文，用于预选卡片、预览、上下循环。
- JSON：包含 `12345678901234567890`、`1.0`、`0.1000`、数组和两层对象。字幕不要把当前按钮概括成未实现的树编辑器。
- 二维码：无私人参数的示例文本／链接；不要拍到登录码。
- Markdown：标题、任务列表、宽表、代码块和一张简单 Mermaid；额外准备一个错误图作为容错镜头。
- 截图：人工准备的演示画面，避免工作聊天、账号或个人信息。
- 长图：可稳定手动滚动的本地长文档；先实测拼接通过，再录正式视频。
- 导出：单独测试目录，避免误删真实剪贴板历史或覆盖个人文件。

可优先使用仓库已有 `Samples/` 样张；实际文件名以目录现状为准，不预先承诺不存在的素材。

## 4. 录制前核对清单

- [ ] 使用包含新默认快捷键的打包版本；录制机若自定义过，字幕与实际绑定一致。
- [ ] 清楚区分全局键和面板内键；⌘E 目前只演示 Markdown、QrCode。
- [ ] 初始页面顺序、循环开关、历史条数和外观已记录。
- [ ] 字号、缩放和鼠标指针大小适合录屏；深浅各拍一组静态样张。
- [ ] 权限状态与讲解一致；未授权 Enter 不说成已粘贴。
- [ ] 截图工具图标、选中态、悬浮态、撤销禁用态已真机检查。
- [ ] 测试保存文件、系统剪贴板的实际结果；控制点不出现在导出图中。
- [ ] 长图至少在拟演示的目标应用中成功一次；不把“采集中”当作拼接正确的证据。
- [ ] 重启行为按当前版本验证，不照旧方案宣称恢复文本或放大状态。
- [ ] 接收机首次安装和设置页已复测；单凭本机开发环境不称为分发验收通过。

## 5. 常见问题的统一口径

| 问题 | 说明方向 |
|---|---|
| 为什么关闭重开面板内容还在，重启却没了？ | 文本页面是本进程会话；Paste 是持久历史 |
| 为什么 ⌘R 刷新失效？ | 默认全局键由 DevBar 接管，可在设置修改 |
| Enter 没有直接粘贴？ | 看授权与前台目标；内容已复制时可手动 ⌘V，不反复承诺自动粘贴 |
| 为什么不能自动滚动长图？ | 当前只有手动滚动，程序负责采样拼接 |
| 为什么截全图提示太长？ | 超过导出边长／面积上限就拒绝，不输出截断图 |
| 保存和 ✓ 一样吗？ | 长图保存写文件，✓ 结束并进入系统剪贴板 |
| 新机器打开设置闪退？ | 先确认使用修复资源打包后的新 ZIP，再收集崩溃记录；不要直接归因于权限 |
| 菜单栏图标没出现？ | 检查运行实例、系统菜单栏显示状态；按验证记录排查，不在视频内自动修改系统偏好 |

## 6. 暂不出现在成片里的内容

双栏实时 Markdown、录屏录音、自动滚动、OCR／AI、截图钉图、分享、另存为、荧光笔，以及尚未实测的性能或多屏承诺。历史方案截图里的按钮不等于当前 DevBar 已有功能。
