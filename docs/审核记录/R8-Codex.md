### 需求方本轮追加决定（优先于旧方案，已按此审核）

1. JSON、Markdown、二维码均为单一内容区，按钮在内容块内部底部，共用背景；没有「结果」区或分隔线。
2. 内容块距面板左右、底部 16pt；块内按钮距左右、底部 12pt。
3. 不显示默认行数、字符数、类型信息；错误提示保留。
4. JSON 只有 JSON、转义 / 反转义、编码 / 解码、清空；取消 URL / Base64 选择；不合法 JSON 只报错、不修复；JSON 不提供长图。
5. 二维码主按钮「预览 / 编辑」，右侧系统复制图标、系统橡皮擦清空图标，图标按钮带背景框。
6. Markdown「预览 / 编辑」，右侧「截全图」（四角取景框）和清空；本轮仍是 R9 待接入的禁用占位。
7. 代码高亮、JSON 树、Mermaid 使用库自带彩色主题（CodeMirror 浅色 defaultHighlightStyle / 深色 One Dark，Shiki github-light / github-dark，Mermaid default / dark）；主题选择以后再做；外观入口只放设置，「自动 / 浅色 / 深色」。
8. 拖到菜单栏图标时显示 400×144 扁平接收面板，只有 DevBar 标题和两个拖放区；选中态只有轻微底色变化和细边框，不黑白反转。
9. Esc 收起输入 / 预览面板、拖入分区和剪贴板悬浮卡片，不受钉住限制。
